  设备连接上后，主机会发送握手帧。
    5A 97 98 0B 09 50 6C 65 61 73 65 20 4C 69 6E 6B A5 A5
    摄像头收到这个帧后，应答：
    5A A7 97 0F 09 50 6C 61 79 20 41 70 6C 69 63 61 74 69 6F 6E 6A A5
    握手成功后，主机就不会发握手帧了，此时摄像头就根据当前的脚本APP来选择发送的数据。
    主菜单/相机/settings/图像分类等无目标场景:类型为对应码,载荷 0 字节(length=0)。

  统一数据载荷说明(所有 stream 模式一致):
    载荷 = N × 10 字节,N = 本帧实际检测目标数量(动态,不固定、不补齐)。
    槽位排序(所有模式一致):按 (x,y) 升序,屏幕最左边为目标1,同 x 按 y 升序。
    每组 10 字节: id(1B) + x(2B BE) + y(2B BE) + w(2B BE) + h(2B BE) + conf(1B)
    坐标单位 = 显示通道 VGA 640×480 像素。
    槽位上限:所有模式统一 25(原"标签 25/注册类 4"区分已取消,学习 ID 上限同步放开)。
    主机须按帧 length 字段解析 N 组,不得假设固定组数/固定字节数。

    conf 字节(每组第 10 字节):
      bit7 = learned(已学习标记):1 = 该目标按过 KEY 学习过(注册类模式命中 DB),
             0 = 未学习目标。标签识别无学习链路,learned 恒 0。
      低 7 位 = 置信度 0~100(标签识别固定 100)。
      主机解析: conf = byte & 0x7F, learned = byte >> 7。

    id=0 语义:未学习目标(如未注册的人脸/物体类别/当前未注册颜色/锁定未注册)。
    id=0 目标坐标有效、conf 低 7 位有效、learned=0、无注册槽号。

    id 语义与槽位上限(按模式):

    | 模式       | 类型码 | 槽位上限 | id 含义                                      |
    |------------|--------|----------|----------------------------------------------|
    | 主菜单     | 0x01   | 0        | 无(0 载荷)                                   |
    | 相机       | 0x02   | 0        | 无(0 载荷)                                   |
    | 人脸识别   | 0x03   | 25       | 注册槽号 1~25(按键注册分配);未注册人脸=0     |
    | 标签识别   | 0x04   | 25       | AprilTag=码值(>255 固定 255)/QR=排序序号     |
    | 物体识别   | 0x05   | 25       | 类别注册槽号 1~25;未注册类别=0               |
    | 颜色识别   | 0x06   | 25       | 注册槽号 1~25;当前色未注册=0                 |
    | 道路识别   | 0x07   | 25       | 车道槽号(检测当前禁用 → 0 载荷)             |
    | 手势识别   | 0x10   | 25       | 注册槽号 1~25                                 |
    | 人体识别   | 0x11   | 25       | 注册槽号 1~25                                 |
    | 物体分类   | 0x12   | 25       | 注册槽号 1~25(锁定未注册目标=0)              |
    | 图像分类   | 0x13   | 0        | 无(0 载荷)                                   |

    排序示例:注册了 ID1/ID2/ID3,画面里 ID3 在最左、ID2 次之 →
    目标1 的 id=3、目标2 的 id=2(槽位按屏幕位置排序,id 值保持注册槽号不变,
    与标签码排序算法一致)。

  名称帧(类型 0x0E,通用:识别名称/内容上传):
    适用模式:标签识别(0x04)、物体识别(0x05)、物体分类(0x12)、手势识别(0x10)。
    无名称/内容的模式(人脸/颜色/人体/道路/主菜单/相机/图像分类)不发名称帧。
    帧:5A A7 97 <len> 0E <payload> <chk> A5
    payload = src_type(1B) + Σ(id(1B) + name_len(1B) + name_utf8),≤ 250B。
      src_type = 所属模式类型码(0x04/0x05/0x10/0x12),主机据此关联最近的数据帧。
      id = 数据帧同轮目标的 id 字段(标签识别:QR=序号/AprilTag=码值;注册类=槽号)。
      name = 识别内容/名称:二维码=payload 原文(网址/数字/中英文)、
             AprilTag=码值字符串、物体识别=COCO 类别名、手势识别=手势名、
             物体分类=obj<槽号>(无类别体系,槽标识占位)。
      未学习目标(id=0)不传名称。
    示例:QR 模式检测到 2 个码,数据帧 id=1、id=2;名称帧
      [0x04][1][13]'http://a.cn'[2][3]'码A' → 主机按 id 关联名称。

  主机→摄像头 切换命令帧(在原有 0xFF 命令链路上):
    5A 97 A7 01 FF <mode> <chk> A5(8 字节,协议不变)
    mode 码(新增):
      0x04 = 标签识别(进入时按上次选择的功能记忆:AprilTag 或二维码,首次默认 AprilTag)
      0x14 = 标签识别-二维码(强制,任何模式可直接切)
      0x15 = 标签识别-AprilTag(强制,任何模式可直接切)
    其余 mode 码语义不变(0x01 回主菜单 / 0x02~0x13 对应模式)。
