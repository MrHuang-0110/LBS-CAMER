# Camera App Three Bugfixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix three camera-app defects: (1) missing Chinese glyphs, (2) absent shutter feedback, (3) `current format not support save function` on capture.

**Architecture:** Bug #1 is a stale font subset — rebuild from current i18n + add the bullet glyphs the UI uses, and drop non-CJK emoji. Bug #3 needs a second sensor channel (chn1, RGB565, VGA) declared at boot before `MediaManager.init()` (per K230 pitfall #15: channels are not addable at runtime); capture snapshots chn1 and saves it. Bug #2's flash overlay becomes reachable once #3 is fixed, but its removal is dead code — drive it from the existing `on_frame()` poll loop.

**Tech Stack:** MicroPython, LVGL v8, K230D BOX, media.sensor multi-channel API, lv_font_conv (Node), Python 3 (host-side font build + test).

---

## File Structure

- `hw/lcd.py` — owns resident Sensor + boot init order. Add chn1 (RGB565/VGA) config **before** `MediaManager.init()`; expose `CAPTURE_CHN`.
- `scripts/camera/app.py` — capture from chn1 + save; make flash feedback reachable and self-removing via `on_frame()`; replace non-CJK emoji/symbols.

```python
# tests/test_font_coverage.py — host-side guard: the font build must cover
# every non-ASCII char the camera app renders. Run with: python -m pytest tests/
import os
import sys

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, os.path.join(ROOT, "tools"))

import build_fonts  # noqa: E402

# Chars the camera UI renders outside i18n JSON (timer bullets etc.).
# Emoji are intentionally NOT here — they are not in the CJK subset and
# the app must use renderable substitutes instead (see Task 4).
REQUIRED_EXTRA = set("●○")


def _built_charset():
    chars = set()
    i18n_dir = os.path.join(ROOT, "resource", "i18n")
    for fn in os.listdir(i18n_dir):
        if fn.endswith(".json"):
            chars |= build_fonts.collect_chars_from_json(
                os.path.join(i18n_dir, fn))
    chars |= build_fonts.collect_chars_from_file(
        os.path.join(ROOT, "tools", "ui_chars.txt"))
    return chars


def test_font_build_covers_camera_i18n():
    built = _built_charset()
    for ch in "图库暂无照片录制中":
        assert ch in built, f"camera glyph {ch!r} missing from font build set"


def test_font_build_covers_ui_bullets():
    built = _built_charset()
    missing = REQUIRED_EXTRA - built
    assert not missing, f"bullet glyphs missing from font build set: {missing}"
```

- [ ] **Step 2: Declare chn1 before MediaManager.init()**

In `hw/lcd.py.__init__`, replace the sensor-config block (the `self.sensor = Sensor(fps=30)` … `self._sensor_running = False` lines) with:

```python
        # chn0：预览通道（RGB888 → OSD1 show_image，板端已验证）。
        # chn1：拍照通道（RGB565 → img.save 支持的格式）。K230 的 RGB888
        # 不支持 save()（报 `current format not support save function`），
        # 且通道必须在 MediaManager.init() 之前一次性声明全（池不可重建，
        # 见 K230 坑 #15）。故在此同时配置 chn0(预览) 与 chn1(拍照)。
        self.sensor = Sensor(fps=30)
        self.sensor.reset()
        # chn0 — 预览
        self.sensor.set_framesize(Sensor.VGA, chn=CAM_CHN_ID_0)
        self.sensor.set_pixformat(Sensor.RGB888, chn=CAM_CHN_ID_0)
        # chn1 — 拍照保存（RGB565 支持 jpg/bmp save）
        self.sensor.set_framesize(Sensor.VGA, chn=CAM_CHN_ID_1)
        self.sensor.set_pixformat(Sensor.RGB565, chn=CAM_CHN_ID_1)
        self.capture_chn = CAM_CHN_ID_1
        self._sensor_running = False
```

- [ ] **Step 3: Expose capture channel via accessor docstring**

In `hw/lcd.py.get_sensor`, update the docstring to note dual channels (replace the existing docstring body):

```python
    def get_sensor(self):
```

```python
    def _flash_feedback(self):
        """拍照白闪反馈 — 创建半透明白层，由 on_frame() 轮询在 ~120ms 后删除
        （K230 MicroPython 无 lv.timer，统一走 on_frame 帧驱动）。"""
        if self._preview_bg is None:
            return
        import time as _time
        flash = lv.obj(self._preview_bg)
        flash.set_size(lv.pct(100), lv.pct(100))
        flash.set_pos(0, 0)
        flash.set_style_bg_color(lv.color_hex(WHITE), 0)
        flash.set_style_bg_opa(160, 0)
        flash.set_style_border_width(0, 0)
        flash.set_style_radius(0, 0)
        flash.clear_flag(lv.obj.FLAG.SCROLLABLE)
        flash.clear_flag(lv.obj.FLAG.CLICKABLE)
        self._flash_obj = flash
        self._flash_start = _time.ticks_ms()
```

- [ ] **Step 4: Drive flash removal from on_frame**
