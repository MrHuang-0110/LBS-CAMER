# 设置页重构设计

> 日期：2026-06-12
> 状态：待实施

## 背景

当前设置页存在三个问题：
1. **布局不符合预期**：使用 Tab 切换方式，用户希望改为 iOS 风格左右分栏列表
2. **中文字体部分缺失**：Phase2 字体字符集未覆盖设置页所有中文字符
3. **返回按钮图标不显示**：使用 Unicode `←` 字符，demo 字体（ASCII only）无此字形

## 设计

### 整体布局（640×480）

```
┌──────────────────────────────────────────────┐
│  ◀  设置                       40px 返回栏   │
├──────────────┬───────────────────────────────┤
│              │                               │
│  ┌────────┐  │   ┌───────────────────────┐   │
│  │🌐 语言 │  │   │ 中文            ✓     │   │
│  └────────┘  │   │ English               │   │
│  ┌────────┐  │   └───────────────────────┘   │
│  │ℹ️ 关于 │  │                               │
│  └────────┘  │                               │
│              │                               │
│  224px 左栏  │     416px 右栏                │
│  (35%)       │     (65%)                     │
├──────────────┴───────────────────────────────┤
└──────────────────────────────────────────────┘
```

### 返回栏

- 高 40px，全宽
- 左侧返回按钮：使用 `back.png`（64×64 → 缩放到 32×32），点击触发 `ctx.request_exit()`
- 标题：body 字体，白色，居中
- 背景：`#222222`，不透明

### 左栏（功能列表）

- 宽 224px（640×35%），背景 `#1A1A1A`
- 内容区 y 起始：返回栏下方（40px）
- 每行结构：
  - 行高 56px
  - 左边距 12px：图标 36×36（从 128×128 缩放）
  - 图标右侧 12px：功能名（body 字体，白色）
  - 右侧 8px：`>` 指示符（body 字体，灰色 `#9E9E9E`）
- 选中行：背景 `#2A2A2A`
- 非选中行：背景 `#1A1A1A`（与栏背景融合）
- 默认选中第一项（语言）
- 点击行：切换选中 → 刷新右栏内容

### 右栏（内容区）

- 宽 416px，背景 `#222222`，圆角 14px 容器
- 内容区 y 起始：返回栏下方 + 8px 间距 = 48px
- 上下内边距 8px

**语言内容**：
- 中文行 + English 行
- 行高 48px，背景 `#2A2A2A`，圆角 10px
- 当前语言右侧显示指示符（用背景色高亮 `#2A5298` 替代 ✓ 字符，避免字形缺失问题）
- 点击行：切换语言 → `lang.switch(code)` + `config.save()` + `event_bus.emit('lang_changed')`

**关于内容**：
- 6 行键值对，行高 44px
- 左侧键名：body 字体，灰色 `#9E9E9E`
- 右侧值：body 字体，白色
- 数据来源：`config.get('version', 'v0.1.0')` + 硬编码常量

### 图标资源

| 图标 | 文件路径 | 原始尺寸 | 显示尺寸 | 用途 |
|------|----------|----------|----------|------|
| 返回箭头 | `/resource/icons/settings_icon/back.png` | 64×64 | 32×32 | 返回栏按钮 |
| 语言图标 | `/resource/icons/settings_icon/Language.png` | 128×128 | 36×36 | 左栏语言行 |
| 关于图标 | `/resource/icons/settings_icon/about.png` | 128×128 | 36×36 | 左栏关于行 |

### 中文字体缺失修复

- 在 `tools/ui_chars.txt` 中补全设置页所有中文字符（如果尚未覆盖）
- 重新运行 `build_fonts.py --run` 生成 Phase2 字体
- 确保所有界面中文文本（i18n JSON + 硬编码值）的字形都被包含
