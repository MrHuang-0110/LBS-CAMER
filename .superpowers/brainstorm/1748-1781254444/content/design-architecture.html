设计 §1 — 架构与显示栈

显示层叠模型

LVGL UI 层（顶栏 + 底栏 + 计时器）— 前景，不透明区域遮挡相机
↓ 透明区域（预览区 640×376）↓
VIDEO1 层 — Sensor 相机画面 — 背景
  • Sensor 通过 Display.bind_layer(layer=VIDEO1) 输出到视频层
  • LVGL 保持初始化，渲染 UI 到前景层
  • 预览区 LVGL 背景设 全透明（bg_opa=0），让 VIDEO1 层透出

ScriptRunner 改动

_switch_mode_for('stream')不再调 lv.deinit()，LVGL 全程存活。仅绑定 Sensor 到 VIDEO1。
BackBar 创建时机由相机脚本自己管理顶栏（非统一 BackBar），因为顶栏布局不同（居中标题）
_switch_to_lvgl_mode()仅释放 Sensor/VIDEO1，不重建 LVGL（因为从未销毁）

图库子页面

  • 同一 CameraApp 内的视图切换（类似 settings 的 _render_language / _render_about）
  • 进入时扫描 /data/photo/ 目录，按文件修改时间倒序排列

  • 点击照片可全屏查看，再次点击返回列表
  • 顶栏与相机同布局：左返回 + 居中「图库」
