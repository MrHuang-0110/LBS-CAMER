数据流

📷 拍照流程

  1. 按快门 → 蜂鸣 30ms
  2. Sensor 捕获当前帧（YUV → JPEG）
  3. 写入 /data/photo/IMG_YYYYMMDD_HHMMSS.jpg
  4. 屏幕短暂闪烁反馈

🎬 录像流程

  1. 按红圆 → 开始录制
  2. 每帧编码写入 /data/photo/VID_YYYYMMDD_HHMMSS.avi
  3. 预览区顶部显示计时器 ● 00:00:01...
  4. 按红方 → 停止录制，关闭文件

🖼 图库加载

  1. 进入图库 → os.listdir('/data/photo/')
  2. 过滤 .jpg/.bmp/.avi
  3. os.stat() 取 mtime，按时间倒序
  4. 构建 LVGL 列表行

⚠️ I/O 注意

  • /data/photo/ 可能是内部 flash（非 SD），不触发 DMA 死锁
  • 如遇死锁，退化为内存缓冲 + 退出时批量写入
  • 拍照时短时间 I/O，录像时持续 I/O（需验证）
