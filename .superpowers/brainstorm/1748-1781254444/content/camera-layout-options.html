相机 APP — 布局方案选择

当前代码全屏预览（方案 A），但 LVGL 被完全关闭，无法显示任何 UI 叠加层（连返回栏都看不到）。你想换成哪种布局？

A

全屏预览（当前）

相机 640×480 满屏，无任何 UI 叠加。返回依赖触摸屏边缘手势或硬件按键。性能最优，但无视觉反馈。

B

全屏预览 + 顶部返回栏

相机满屏，顶部叠加 52px 半透明返回栏（与设置页一致的 BackBar）。需要 LVGL 和相机同时运行，利用 K230 多层显示。

C

预览 + 底部控制栏

相机预览占上方大部分，底部有控制栏（拍照按钮、返回按钮等）。类似手机相机 APP 的经典布局。

D

预览 + 顶部栏 + 底部栏

顶部 52px 返回栏 + 底部控制栏，中间相机预览区域自动缩放。功能最完整，但实现最复杂。
