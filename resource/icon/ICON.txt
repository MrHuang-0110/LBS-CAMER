/resource/icons/ — icon resources root.

Each script owns one icon directory: /resource/icons/<script_id>_icon/.
All icons used by that script should be placed in its own directory.

Main menu entry icons are managed by the main menu resource directory:
  /resource/icons/menu_icon/

Main menu card: left icon + center function name ONLY (no description).
